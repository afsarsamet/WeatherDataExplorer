# WeatherDataExplorer
A Python toolkit for historical weather data analysis

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Usage

```bash
python main.py      # run the demo on data/budapest.csv
pytest              # run the test suite
```
